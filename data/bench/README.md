# Benchmark data provenance and license

The source lyric excerpts in this directory are sampled from the test split of
Longshen Ou, Xichu Ma, Min-Yen Kan, and Ye Wang (2023), “Songs Across Borders:
Singable and Controllable Neural Lyric Translation.” The source dataset is
available at <https://huggingface.co/datasets/LongshenOu/lyric-trans-en2zh-data>
under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0
International license (CC BY-NC-SA 4.0).

Files in this directory that contain those excerpts or adaptations of them,
including sampled windows, translations, traces, and evaluation results, are
distributed under CC BY-NC-SA 4.0 and are not covered by the repository's
Apache-2.0 software license. See
<https://creativecommons.org/licenses/by-nc-sa/4.0/> for the license terms.

The complete upstream lyric corpus is not included here. These files contain
only the sampled evaluation windows and the artifacts required to reproduce the
reported experiments.
